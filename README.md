# 🎯 NHL Greedy Simulator

*A sleek personal app that forecasts the rest of a season and “nudges” non-user games to help your team finish Top-3 in its division. Fast, deterministic, and built for the web.*


## What it does
- Simulates remaining games and steers divisional outcomes to keep the 3rd-place bar reachable while minimizing rival points.  
- Deterministic results — same inputs → same outputs.  
- Lightweight greedy logic (no heavy search), ideal for interactive use.

## Tech stack
- Next.js • React • Tailwind CSS

## Assumptions (simple by design)
- Clean regulation wins only (2 pts); no OT/SO points.  
- Focus on division standings; target = Top-3.  

> Personal project — intentionally minimal and easy to extend.
